# 📖 Overview

SwasthSetu is an AI-powered Healthcare Management Platform that connects Patients, Doctors, and Administrators on one secure platform.

The system provides:

- 🩺 Online Doctor Consultation
- 🎥 Video Consultation
- 🤖 AI Healthcare Chatbot
- 💊 Medicine Reminder
- 📅 Appointment Booking
- 📄 Digital Prescription
- ❤️ Health Record Management
- 🔔 Real-Time Notifications

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/shivamdevraj02/Healthcare.git

cd Healthcare
```

---

## Backend Setup

```bash
cd backend

npm install

npm run dev
```

---

## Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

---

# 🔑 Environment Variables

## Backend (.env)

```env
PORT=5000

MONGO_URI=your_mongodb_uri

JWT_SECRET=your_secret

JWT_EXPIRES_IN=7d

CLIENT_URL=http://localhost:5173

GEMINI_API_KEY=your_gemini_api_key

EMAIL_USER=your_email

EMAIL_PASS=your_email_password
```

---

## Frontend (.env)

```env
VITE_API_URL=http://localhost:5000
```

For ZEGO Cloud

```env
VITE_ZEGO_APP_ID=YOUR_APP_ID

VITE_ZEGO_SERVER_SECRET=YOUR_SERVER_SECRET
```
